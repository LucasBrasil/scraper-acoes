# Apps Script

Este diretório receberá o projeto sincronizado com o Google Apps Script.

O código é organizado com engines no núcleo, modelos de domínio independentes, contratos de persistência e adaptadores de infraestrutura. Não há funções executáveis, gatilhos, integrações ou regras de negócio nesta etapa.

## Sprint 2

O menu **MS Analytics → Atualizar Estatísticas** lê somente a aba `Histórico` e atualiza a aba `Estatísticas`. Consulte os contratos das abas em `../sheets/specs/` antes de usar a funcionalidade.
